# Updates and maintenance

Panel, Backend, Frontend, and Node are real forks of the matching official Remnawave repositories.
Each maintained `singbox` branch has automated upstream synchronization.

The automation:

1. fetches the official `main` branch;
2. merges it in an isolated GitHub Actions checkout;
3. runs repository-specific validation;
4. pushes only a tested merge;
5. publishes Backend and Node images where applicable.

If the merge conflicts or validation fails, the public `singbox` branch is not updated. The
failure must be repaired on a temporary branch while preserving both the new official behavior and
the fork compatibility invariants.

Custom features are kept behind narrow adapters, optional fields, additive migrations, and focused
regression tests so they can be carried onto later official versions.
